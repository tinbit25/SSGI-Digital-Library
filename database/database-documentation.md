# Database Technical Documentation — SSGI Digital Library Portal

## Executive Summary & Architecture Overview
The **SSGI Digital Library Portal** database (`ssgi_digital_library`) is a production-ready MySQL 8.0+ relational schema designed for the Ethiopian Space Science and Geospatial Institute (SSGI). It provides structured storage, audit trails, and high-performance indexing tailored to work seamlessly with **Laravel 12 (Eloquent ORM & Spatie Permission)** and the **Qdrant Vector Database**.

### Critical Architectural Pillars:
1. **Strict Read-Only Enforcement:** The portal permits reading exclusively via a secure online document stream. No tables exist for physical borrowing, QR checkouts, book returns, fines, or raw file downloads.
2. **Hybrid RAG AI Separation:** Natural language textual paragraphs extracted from library PDFs reside in MySQL inside the `resource_chunks` table. High-dimensional numeric embedding vectors generated by the AI model reside strictly inside **Qdrant**. The relational connection is forged via the unique `qdrant_vector_id` column.
3. **Structured Feedback vs. Chat:** Real-time user chat and direct messaging are intentionally excluded. Asynchronous communication is handled via broadcast `notifications` and structured trouble tickets in `feedback`.

## Table Descriptions & Specifications

### 1. `roles`
* **Purpose:** Defines Role-Based Access Control (RBAC) tiers within the portal (`Administrator`, `Librarian`, `Staff`, and `Guest`). Designed to adhere strictly to Spatie Laravel Permission schema conventions.
* **Relationships:**
  * `HasMany` to `users` (One role classifies many user accounts).
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Unique internal identifier |
  | `name` | `VARCHAR(255)` | NOT NULL, Unique (with guard), Indexed | Name of access role |
  | `guard_name` | `VARCHAR(255)` | NOT NULL, Default `'web'` | Authentication guard targeting web/API |
  | `created_at` / `updated_at` | `TIMESTAMP` | Nullable | Standard Laravel Eloquent audit timestamps |

* **Example Usage (Laravel Eloquent):**
  ```php
  // Fetching all staff members assigned to the 'Librarian' role
  $librarians = Role::where('name', 'Librarian')->first()->users;
  ```

---

### 2. `users`
* **Purpose:** Central entity storing authenticated user accounts across all institutional tiers. Integrates with Laravel Sanctum for API token issuance and password hashing.
* **Relationships:**
  * `BelongsTo` to `roles` (via `role_id`).
  * `HasMany` to `resources` (as `uploaded_by`).
  * `HasMany` to `access_logs`, `feedback`, `ai_chat_history`, and `notification_users`.
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Primary key |
  | `role_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `roles.id`, Indexed | Foreign key assigning RBAC tier |
  | `name` | `VARCHAR(255)` | NOT NULL | Complete staff or trainee name |
  | `email` | `VARCHAR(255)` | NOT NULL, Unique, Indexed | Institutional email address for login |
  | `email_verified_at` | `TIMESTAMP` | Nullable | Verification verification timestamp |
  | `password` | `VARCHAR(255)` | NOT NULL | Bcrypt / Argon2id secure password hash |
  | `remember_token` | `VARCHAR(100)` | Nullable | Token persisting web authentication state |
  | `created_at` / `updated_at` | `TIMESTAMP` | Nullable (Indexed on `created_at`) | Creation and modification tracking |
  | `deleted_at` | `TIMESTAMP` | Nullable, Indexed | Soft delete timestamp preserving audit trails |

* **Example Usage (Laravel Eloquent):**
  ```php
  // Authenticating user and checking if they hold Librarian permissions
  $user = User::with('role')->where('email', 'abebe.k@ssgi.gov.et')->first();
  if ($user->role->name === 'Librarian') {
      // Allow upload access
  }
  ```

### 3. `categories`
* **Purpose:** Normalizes technical disciplines (e.g., *Space Science & Astronomy*, *Geospatial GIS*, *Satellite Engineering*) in a self-referencing adjacency list to allow nested subcategories without duplicate table proliferation.
* **Relationships:**
  * `BelongsTo` to `categories` (parent category via `parent_id`).
  * `HasMany` to `categories` (subcategories via `parent_id`).
  * `HasMany` to `resources` (via `category_id`).
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Primary key |
  | `parent_id` | `BIGINT UNSIGNED` | Nullable, FK to `categories.id`, Indexed | Optional parent domain |
  | `name` | `VARCHAR(255)` | NOT NULL, Indexed | Display title of scientific discipline |
  | `slug` | `VARCHAR(255)` | NOT NULL, Unique, Indexed | SEO and URL friendly filter string |
  | `description` | `TEXT` | Nullable | Narrative explanation of catalog classification |
  | `created_at` / `updated_at` | `TIMESTAMP` | Nullable | Audit timestamps |
  | `deleted_at` | `TIMESTAMP` | Nullable, Indexed | Soft delete timestamp |

* **Example Usage (Laravel Eloquent):**
  ```php
  // Eager load category with all associated published library resources
  $category = Category::with(['resources' => function($q) {
      $q->where('is_published', true)->latest();
  }])->where('slug', 'satellite-engineering')->first();
  ```

### 4. `resources`
* **Purpose:** Core repository cataloging books, research papers, and technical training guides. Protects underlying digital documents by utilizing an unguessable `uuid` for all viewer streaming routes rather than sequential database primary keys.
* **Relationships:**
  * `BelongsTo` to `categories` (via `category_id`).
  * `BelongsTo` to `users` (authoring librarian via `uploaded_by`).
  * `HasMany` to `resource_chunks` (for AI RAG processing).
  * `HasMany` to `access_logs` and `notifications`.
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Internal relational primary key |
  | `uuid` | `VARCHAR(36)` | NOT NULL, Unique, Indexed | Public route streaming token (preventing scraping) |
  | `category_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `categories`, Indexed | Discipline association |
  | `title` | `VARCHAR(255)` | NOT NULL, Indexed | Document title (Indexed for rapid keyword discovery)|
  | `author` | `VARCHAR(255)` | NOT NULL | Credited researcher or taskforce |
  | `abstract` | `TEXT` | Nullable | Document synopsis or summary |
  | `file_path` | `VARCHAR(512)` | NOT NULL | Secure private storage disk path outside web root |
  | `file_hash` | `VARCHAR(64)` | NOT NULL, Unique (SHA-256) | File cryptographic hash preventing redundant storage |
  | `file_size_bytes`| `BIGINT UNSIGNED` | Nullable | Digital file size in bytes |
  | `page_count` | `INT UNSIGNED` | Nullable | Document total page count |
  | `is_published` | `TINYINT(1)` | NOT NULL, Default `1`, Indexed | Visibility status controlled by library administration|
  | `uploaded_by` | `BIGINT UNSIGNED` | NOT NULL, FK to `users`, Indexed | Librarian responsible for ingesting file |
  | `created_at` / `updated_at` | `TIMESTAMP` | Nullable (Indexed on `created_at`) | Upload timestamps (Indexed for newest sorting) |
  | `deleted_at` | `TIMESTAMP` | Nullable, Indexed | Soft delete timestamp |

* **Example Usage (Laravel Eloquent & Secure Stream Controller):**
  ```php
  // Looking up a resource by UUID for protected online viewing
  $resource = Resource::where('uuid', $request->uuid)->where('is_published', true)->firstOrFail();
  
  // Return file stream without attachment header (prevents direct download)
  return response()->file(storage_path('app/' . $resource->file_path), [
      'Content-Type' => 'application/pdf',
      'Content-Disposition' => 'inline; filename="' . $resource->title . '.pdf"'
  ]);
  ```

### 5. `resource_chunks`
* **Purpose:** The relational backbone of the AI RAG module. Divides uploaded library PDFs into smaller textual segments (`content`) and links them directly to their calculated multidimensional vector points stored inside the external **Qdrant** database via `qdrant_vector_id`.
* **Relationships:**
  * `BelongsTo` to `resources` (via `resource_id`).
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Primary key |
  | `resource_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `resources`, Indexed | Parent document reference (`ON DELETE CASCADE`) |
  | `chunk_index` | `INT UNSIGNED` | NOT NULL | Sequential structural position of text in document |
  | `content` | `MEDIUMTEXT` | NOT NULL | Extracted raw text segment fed to embedding model |
  | `qdrant_vector_id`| `VARCHAR(255)` | NOT NULL, Unique, Indexed | Exact Point ID corresponding to Qdrant storage |
  | `created_at` / `updated_at` | `TIMESTAMP` | Nullable | Extraction and synchronization timestamps |

* **Example Usage (Hybrid RAG Search Query in Laravel):**
  ```php
  // 1. Backend searches Qdrant via embedding API and retrieves matching Point IDs
  $qdrantMatches = ['qdr_pt_10001_etrss1_s1', 'qdr_pt_10002_etrss1_s2'];
  
  // 2. Eloquent retrieves corresponding textual paragraphs and parent resource metadata from MySQL
  $chunks = ResourceChunk::with('resource')
      ->whereIn('qdrant_vector_id', $qdrantMatches)
      ->get();
      
  // 3. Text chunks are compiled into LLM Context window for response generation
  ```

### 6. `access_logs`
* **Purpose:** Security audit ledger capturing every online reading session. Verifies compliance with institutional data rights by tracking reader identity, timestamp, IP address, and client software without allowing static file downloads.
* **Relationships:**
  * `BelongsTo` to `users` (via `user_id`).
  * `BelongsTo` to `resources` (via `resource_id`).
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Primary key |
  | `user_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `users`, Indexed | Reader account initiating session |
  | `resource_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `resources`, Indexed| Document being consumed in viewer |
  | `ip_address` | `VARCHAR(45)` | Nullable | Reader's IP address (supports IPv4 and IPv6) |
  | `user_agent` | `VARCHAR(512)` | Nullable | Browser and hardware OS string |
  | `accessed_at` | `TIMESTAMP` | NOT NULL, Default `NOW()`, Indexed | Exact access time (Compound indexed with resource) |

* **Example Usage (Laravel Eloquent Analytics):**
  ```php
  // Recording a document access event in a Laravel listener or controller
  AccessLog::create([
      'user_id' => auth()->id(),
      'resource_id' => $resource->id,
      'ip_address' => request()->ip(),
      'user_agent' => request()->userAgent()
  ]);

  // Querying top 5 most frequently consulted space science papers this month
  $topResources = Resource::withCount(['accessLogs' => function($query) {
      $query->where('accessed_at', '>=', now()->subMonth());
  }])->orderByDesc('access_logs_count')->take(5)->get();
  ```

### 7. `feedback`
* **Purpose:** Replaces traditional real-time chat with a formal, structured feedback loop. Staff and guest trainees use this mechanism to submit system suggestions, problem reports, missing literature requests, or platform improvement ideas for librarian review.
* **Relationships:**
  * `BelongsTo` to `users` (via `user_id`).
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Primary key |
  | `user_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `users`, Indexed | Staff or trainee submitting feedback |
  | `category` | `ENUM(...)` | NOT NULL, Default `'suggestion'`| `'suggestion'`, `'problem'`, `'missing_resource'`, or `'improvement'` |
  | `subject` | `VARCHAR(255)` | NOT NULL | Concise overview of report |
  | `message` | `TEXT` | NOT NULL | Detailed problem description or asset request |
  | `status` | `ENUM(...)` | NOT NULL, Default `'pending'`, Indexed| `'pending'`, `'under_review'`, `'resolved'`, or `'dismissed'`|
  | `admin_response`| `TEXT` | Nullable | Actionable resolution reply left by librarian or admin|
  | `created_at` / `updated_at` | `TIMESTAMP` | Nullable (Indexed on `created_at`) | Timestamp tracking (Compound indexed with status)|

* **Example Usage (Laravel Eloquent):**
  ```php
  // Librarian fetching all unresolved missing resource requests ordered by creation time
  $pendingRequests = Feedback::with('user')
      ->where('category', 'missing_resource')
      ->whereIn('status', ['pending', 'under_review'])
      ->latest()
      ->get();
  ```

### 8. `notifications`
* **Purpose:** Broadcast announcement engine powered by Laravel Mail and Notification events. Utilized by librarians to publish alerts regarding scheduled maintenance or promote newly archived research documents.
* **Relationships:**
  * `BelongsTo` to `resources` (optional link via `resource_id`).
  * `BelongsTo` to `users` (authoring librarian via `created_by`).
  * `HasMany` to `notification_users` (recipient read-receipt mapping).
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Primary key |
  | `resource_id` | `BIGINT UNSIGNED` | Nullable, FK to `resources`, Indexed| Optional link to newly published document |
  | `title` | `VARCHAR(255)` | NOT NULL | Notification header |
  | `message` | `TEXT` | NOT NULL | Body narrative of the broadcast alert |
  | `type` | `VARCHAR(50)` | NOT NULL, Default `'announcement'`, Indexed | Message classification (`'new_resource'`, `'alert'`) |
  | `created_by` | `BIGINT UNSIGNED` | Nullable, FK to `users`, Indexed | Authoring librarian account |
  | `created_at` / `updated_at` | `TIMESTAMP` | Nullable (Indexed on `created_at`) | Creation timestamp |

* **Example Usage (Laravel Eloquent):**
  ```php
  // Creating a system broadcast when a librarian publishes a new manual
  $notice = Notification::create([
      'resource_id' => $resource->id,
      'title' => 'New Resource: ' . $resource->title,
      'message' => 'A new technical document is now available for institutional research.',
      'type' => 'new_resource',
      'created_by' => auth()->id()
  ]);
  ```

### 9. `notification_users`
* **Purpose:** Many-to-many junction table linking broadcast `notifications` to target `users`. Natively supports read receipts via a timestamped `read_at` column, enabling React frontend badge counting and unread inbox sorting.
* **Relationships:**
  * `BelongsTo` to `notifications` (via `notification_id`).
  * `BelongsTo` to `users` (via `user_id`).
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Primary key |
  | `notification_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `notifications`, Indexed | Target broadcast message (`ON DELETE CASCADE`) |
  | `user_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `users`, Indexed | Recipient staff or trainee (`ON DELETE CASCADE`) |
  | `read_at` | `TIMESTAMP` | Nullable, Indexed | Read timestamp (NULL represents unread status) |

* **Example Usage (Laravel Eloquent Relationship & Unread Counter):**
  ```php
  // Marking a notification as read when user views it in React frontend
  NotificationUser::where('user_id', auth()->id())
      ->where('notification_id', $notificationId)
      ->update(['read_at' => now()]);

  // Counting total unread broadcasts for the currently logged-in researcher
  $unreadCount = NotificationUser::where('user_id', auth()->id())
      ->whereNull('read_at')
      ->count();
  ```

### 10. `ai_chat_history`
* **Purpose:** Persists generative question-answering loops between researchers and the AI Library Assistant. Groups consecutive turns via a `session_id` UUID and preserves academic accountability by saving structured document citation references in a MySQL `JSON` data type column.
* **Relationships:**
  * `BelongsTo` to `users` (via `user_id`).
* **Columns:**
  | Column | Type | Modifiers / Constraints | Description |
  | :--- | :--- | :--- | :--- |
  | `id` | `BIGINT UNSIGNED` | PK, Auto Increment | Primary key |
  | `session_id` | `VARCHAR(36)` | NOT NULL, Indexed | UUID binding sequential conversational turns together |
  | `user_id` | `BIGINT UNSIGNED` | NOT NULL, FK to `users`, Indexed| Researcher communicating with AI |
  | `role` | `VARCHAR(20)` | NOT NULL | Conversational actor (`'user'` or `'assistant'`) |
  | `message` | `TEXT` | NOT NULL | Prompt text submitted or RAG response generated |
  | `citations` | `JSON` | Nullable | JSON schema listing referenced resources and chunks |
  | `created_at` | `TIMESTAMP` | NOT NULL, Default `NOW()`, Indexed | Message delivery timestamp (Indexed for chronological UI ordering) |

* **Example Usage (Laravel Eloquent RAG Archiving & Retrieval):**
  ```php
  // Storing AI assistant reply alongside JSON formatted RAG source citations
  AiChatHistory::create([
      'session_id' => $activeSessionId,
      'user_id' => auth()->id(),
      'role' => 'assistant',
      'message' => 'ETRSS-1 operates in a Sun-synchronous orbit at 629 km altitude.',
      'citations' => json_encode([
          'resources' => [
              ['id' => 2, 'title' => 'ETRSS-1 Satellite Flight Operations Manual', 'chunk_id' => 'qdr_pt_10001_etrss1_s1']
          ]
      ])
  ]);

  // Retrieving full chat thread chronologically for React chat window
  $history = AiChatHistory::where('session_id', $activeSessionId)
      ->where('user_id', auth()->id())
      ->orderBy('created_at', 'asc')
      ->get();
  ```

## Production Indexing Strategy Summary

| Index Focus Area | Applied Index / Column Targets | Architectural Rationale |
| :--- | :--- | :--- |
| **User Identification (`email`)** | `users.email` (Unique Index) | Instantaneous Sanctum authentication lookups and credential validation. |
| **Resource Discovery (`title`)** | `resources.title` (Index) | Accelerated keyword pattern matching during portal digital library searches. |
| **Taxonomy (`category`)** | `resources.category_id` (Index)<br>`categories.slug` (Unique Index)<br>`categories.name` (Index) | Instant filtering of research papers across institutional scientific domains. |
| **Foreign Keys** | Explicit `KEY` on all FK columns across all 10 tables | Prevents full table scans during Eloquent relationship joins (`with()`, `whereHas()`). |
| **Timestamps** | `access_logs.accessed_at`<br>`notifications.created_at`<br>`notification_users.read_at`<br>`ai_chat_history.created_at`<br>`resources.created_at`<br>`deleted_at` on all soft-deletable entities | Enhances time-series analytics, unread calculation speed, chronological sorting, and soft-delete exclusion performance without overhead. |
